关于这片自留地

记录所学，收藏日常。很高兴在这里遇见你。

你好，我是 hori。

欢迎来到我的个人博客。这里是一片留给文字的小天地，用来安放学习中的收获、探索中的思考，以及生活中不想忘记的瞬间。

为什么写博客？

有些问题，在写下来的时候才变得清晰；有些平凡的日子，回头看时也有自己的光。希望这里的记录，能让想法一点一点积累，也能给偶然路过的你带来一点启发。

从哪里开始？

  • 去 文章分组 里，循着兴趣随处看看。
  • 去 归档 里，沿着时间慢慢读。
  • 或者使用右上角的搜索，寻找一个关键词。

你也可以在 GitHub 找到我。

保持好奇，认真生活。慢慢来，也很好。
